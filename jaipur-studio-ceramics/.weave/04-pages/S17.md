## S17 Discount codes (/discount-codes)
Let the owner review promotion codes and deactivate a code that should no longer work.
Roles: shopOwner · Frame: FR02 · Flows: F24, F25, F26

1. Reads the title and knows they are reviewing discount codes.
2. Can choose "Create discount code", the main action, which goes to /discount-codes/new.
3. Sees each discount code as a table row with code (FD17), discount type (FD18), discount value (FD19), expiry date (FD20) and status as Active or Deactivated.
4. Can deactivate an Active code with its quiet row action, which opens D02.

When there are no discount codes yet:
   1. Reads "No discount codes yet. Create one for your next promotion."
   2. Can choose "Create discount code", which goes to /discount-codes/new.

Route folder: `web/app/(routes)/(app)/discount-codes`.
Loads its records through: listDiscountCodes.

## D02 Deactivate this code? (dialog)
Confirm stopping an active discount code from being used at checkout.
Opened from: S17 · Flows: F26

1. Reads "Deactivate this code?" and the discount code (FD17).
2. Can choose "Deactivate", which deactivates the code, shows a toast confirming the code is deactivated, and goes back to /discount-codes.
3. Can choose Cancel, which closes the dialog and changes nothing.

When deactivating the code fails:
   1. Reads that deactivating failed and the code is still Active.
   2. Can choose "Deactivate", which tries deactivating the code again.
   3. Can choose Cancel, which closes the dialog and changes nothing.
