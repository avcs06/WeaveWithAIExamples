## S12 The order's reference, as in "Order JSC-1024" (/orders/[orderId])
Show everything the owner needs to collect UPI payment, pack, ship or hold an order for pickup, and move its payment and fulfilment status.
Roles: shopOwner · Frame: FR02 · Flows: F14, F15, F16, F17, F18, F28

1. Sees the order's reference as the title, as in "Order JSC-1024".
2. Sees buyer name (FD10), phone number (FD11), items with glaze and size and quantities, discount used, shipping and total, payment status, and fulfilment choice with delivery address, city and PIN code for courier orders.
3. Can choose "Mark as paid" when the order is Unpaid, which updates payment status to Paid, keeps fulfilment status unchanged, and shows a toast confirming the order is Paid.
4. Can choose "Mark as packed" when the order is New, which updates fulfilment status to Packed and shows a toast confirming the order is Packed.
5. Can choose "Mark as shipped" when the order is a Packed courier order, which updates fulfilment status to Shipped and shows a toast confirming the order is Shipped.
6. Can choose "Mark as picked up" when the order is a Packed studio pickup order, which updates fulfilment status to Picked Up and shows a toast confirming the order is Picked Up.
7. Can choose "Cancel order" when the order is New or Packed, which opens D03.
8. Can choose "Orders", which goes to /orders.

When the order cannot be found:
   1. Reads "This order cannot be found."
   2. Can choose "Orders", which goes to /orders.

When the order is New:
   1. Sees the order details with fulfilment status New.
   2. Can choose "Mark as packed", which updates the order to Packed and shows a toast confirming the order is Packed.
   3. Can choose "Cancel order", which opens D03.

When the order is Packed and is a courier delivery order:
   1. Sees the order details with fulfilment status Packed.
   2. Can choose "Mark as shipped", which updates the order to Shipped and shows a toast confirming the order is Shipped.
   3. Can choose "Cancel order", which opens D03.

When the order is Packed and is a studio pickup order:
   1. Sees the order details with fulfilment status Packed.
   2. Can choose "Mark as picked up", which updates the order to Picked Up and shows a toast confirming the order is Picked Up.
   3. Can choose "Cancel order", which opens D03.

When the owner tries to mark an order Packed but it is no longer New:
   1. Sees the order details with its current payment and fulfilment status.
   2. Reads "Only a New order can be marked Packed."

When the owner tries to mark an order Shipped but it is not Packed or is not a courier order:
   1. Sees the order details with its current fulfilment status.
   2. Reads "Only a Packed courier order can be marked Shipped."

When the owner tries to mark an order Picked Up but it is not Packed or is not a studio pickup order:
   1. Sees the order details with its current fulfilment status.
   2. Reads "Only a Packed studio pickup order can be marked Picked Up."

When the order is already Paid:
   1. Sees the order details with its current payment and fulfilment states.
   2. Reads "This order is already Paid."

Route folder: `web/app/(routes)/(app)/orders/[orderId]`.
Loads its records through: getOrder, getPiece.

## D03 Cancel this order? (dialog)
Confirm cancelling a New or Packed order and restoring its variant stock.
Opened from: S12 · Flows: F18

1. Reads "Cancel this order?" and that the stock of its ordered variants will be restored.
2. Can choose "Cancel order", which cancels the order, restores the stock, shows a toast confirming the order is cancelled, and goes back to /orders/[orderId].
3. Can choose Cancel, which closes the dialog and changes nothing.

When cancelling the order fails:
   1. Reads that cancelling failed and the order and stock are unchanged.
   2. Can choose "Cancel order", which tries cancelling the order again.
   3. Can choose Cancel, which closes the dialog and changes nothing.

When the order is already Shipped, Picked Up or Cancelled:
   1. Reads "Only a New or Packed order can be cancelled." and sees the order with its current fulfilment status.
   2. Can choose Cancel, which closes the dialog and changes nothing.
