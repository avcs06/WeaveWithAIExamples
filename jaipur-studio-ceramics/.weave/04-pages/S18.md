## S18 Create discount code (/discount-codes/new)
Make a new percentage or fixed-amount promotion code, such as a weekend Instagram offer.
Roles: shopOwner · Frame: FR02 · Flows: F25

1. Reads the title and knows they are creating a discount code.
2. Fills in the discount code form FM03 with Discount code (FD17), Discount type (FD18), Discount value (FD19) and Expiry date (FD20).
3. Can choose "Save", the main action, which saves the code as Active, shows a toast confirming the code is saved, and goes to /discount-codes.
4. Can choose Cancel, which goes to /discount-codes and changes nothing.

When the code is empty or longer than 30 characters, the discount type is missing, the discount value is missing or not greater than zero, a percentage value is greater than 100, or the expiry date is missing or is not a future date:
   1. Sees what is wrong marked and what was typed kept.
   2. Reads the fixes needed for code, discount type, discount value or expiry date.

When saving the code fails:
   1. Sees the entered values kept.
   2. Can choose "Save", which tries saving the code again.

When the code already exists for another discount code, ignoring upper and lower case:
   1. Reads "That code is already used."
   2. Sees what was typed kept so a different code can be entered.

When the owner cancels without saving:
   1. Reads that nothing was saved.
   2. Sees the discount code list as it was at /discount-codes.

Route folder: `web/app/(routes)/(app)/discount-codes/new`.
Loads its records through: nothing.
