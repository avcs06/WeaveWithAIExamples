## S07 Find your order (/order-lookup)
Let a guest buyer find a placed order again with its reference and the phone number from checkout.
Roles: buyer · Frame: FR01 · Flows: F08

1. Reads the title and knows they can find an order with its reference and phone number.
2. Fills in the order lookup form FM04 with Order reference (FD24) and Phone number (FD11).
3. Can choose "Find order", the main action, which shows the same order details with reference, pieces with glaze, size and quantities, discount and shipping totals, total, fulfilment choice and the UPI-later note.
4. Can choose "Browse pieces", which goes to /pieces.

When the order reference is empty or the phone number is not a phone number:
   1. Sees what is wrong marked and what was typed kept.
   2. Reads "Check the order reference and phone number and try again."

When looking up the order fails:
   1. Sees the typed values kept.
   2. Can choose "Find order", which tries the lookup again.

When no order matches the reference together with the phone number:
   1. Reads "No order was found for that reference and phone number. Check the values and try again."
   2. Sees the typed values kept.

Route folder: `web/app/(routes)/(marketing)/order-lookup`.
Loads its records through: lookupOrder, getPiece.
