## S05 Checkout (/checkout)
Let the buyer apply one discount code, give guest checkout details, choose pickup or courier, and place the order without paying online.
Roles: buyer · Frame: FR01 · Flows: F06, F07

1. Reads the title and knows they are placing an order as a guest, with no online payment taken.
2. Sees each cart line with piece name, glaze, size, price and quantity, the discounted subtotal, shipping and the total.
3. Reads that courier shipping is ₹99, free when the discounted subtotal is more than ₹1,500, and studio pickup is free.
4. Reads the studio pickup address and pickup instructions.
5. Fills in Discount code (FD17) and can choose "Apply", which shows the discount taken off the subtotal and shipping recalculated, and replaces any code already applied.
6. Fills in the checkout form FM02 with Buyer name (FD10), Phone number (FD11) and Fulfilment choice (FD12).
7. Fills in Delivery address (FD13), City (FD14) and PIN code (FD15) when Courier delivery is chosen.
8. Can choose "Place order", the main action, which creates the order with an order reference, immediately reduces the stock of the ordered variants, and goes to /order-confirmation/[orderId].
9. Can choose "Open cart", which goes to /cart.

When the cart is empty:
   1. Reads "Your cart is empty. Browse pieces to start your order."
   2. Can choose "Browse pieces", which goes to /pieces.

When the discount code matches no discount code:
   1. Reads "That code is not recognized."
   2. Sees the typed discount code (FD17) kept and the totals without any discount.
   3. Can try another code or place the order without a code.

When the discount code is past its expiry date:
   1. Reads "That code has expired."
   2. Sees the typed discount code (FD17) kept and the totals without any discount.
   3. Can try another code or place the order without a code.

When the discount code has been deactivated by the owner:
   1. Reads "That code is no longer active."
   2. Sees the typed discount code (FD17) kept and the totals without any discount.
   3. Can try another code or place the order without a code.

When checking the discount code fails:
   1. Sees the typed discount code (FD17) and cart kept unchanged.
   2. Can choose "Apply", which tries applying the code again.

When a required checkout value is missing or wrong:
   1. Sees what is wrong marked and what was typed kept.
   2. Reads the fixes needed for name, phone, fulfilment choice, delivery address, city, PIN code or quantity.

When placing the order fails:
   1. Sees all typed checkout values kept.
   2. Can choose "Place order", which tries placing the order again.

When the discount code is invalid, expired or deactivated at placing the order:
   1. Reads "That code cannot be used." and sees totals without the discount.
   2. Sees the other typed values kept.
   3. Can place the order without the code.

When an ordered variant no longer has enough stock left:
   1. Reads which piece with glaze and size is short and how many are left.
   2. Can choose "Open cart", which goes to /cart to fix the quantities before ordering.

Route folder: `web/app/(routes)/(marketing)/checkout`.
Loads its records through: listPieces, getDiscountCode.
